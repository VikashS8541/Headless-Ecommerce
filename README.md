# Aurelo storefront (React + Vite + Tailwind) connected to WordPress

- `npm install`, then `npm run dev` (needs the WordPress site running in Local).
- WordPress address is set in `.env` (`VITE_WP_URL`).
- **Full beginner's guide: [docs/PROJECT-GUIDE.md](docs/PROJECT-GUIDE.md)**
- Import the sample catalogue: `docs/aurelo-products.csv` (WooCommerce > Products > Import).
- Original static design files: `design/`.
